## 🚀 Deployment on Netlify

This website is a zero-build static site, pre-configured for instant deployment on [Netlify](https://www.netlify.com/):

1. **Connect GitHub:** Log in to [Netlify](https://app.netlify.com/) and click **"Add new site" > "Import an existing project"**.
2. **Select Repository:** Choose `Mussab-21/Nova_Nails`.
3. **Build Settings:**
   - **Base directory:** *(Leave blank)*
   - **Build command:** *(Leave blank)*
   - **Publish directory:** `.` (Root directory, as defined in `netlify.toml`)
4. **Deploy:** Click **"Deploy Nova_Nails"** and your site will be live on a `*.netlify.app` domain in seconds!
